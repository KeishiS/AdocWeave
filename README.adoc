= AdocWeave

AdocWeaveは、AsciiDoc文書の確認、整形、HTML変換を行うRust製ツールです。
コマンドライン、WebAssembly、Language Serverを提供します。

== 機能

* AsciiDocを安全なHTMLへ変換します。
* 文法やリンク、表などの問題を行番号付きで表示します。
* 意味を変えずに、対応済みの範囲を整形します。
* VS CodeとZedで診断、補完、定義への移動を提供します。
* ブラウザーや別のアプリケーションに組み込みます。

対応状況はxref:docs/user-guide/syntax-support.adoc[対応している書式]を参照してください。AdocWeaveはAsciiDocの全機能を実装しません。
対応範囲と他の実装との差異はxref:docs/user-guide/compatibility.adoc[AsciiDocとの互換性]に記載します。

== 使用方法

GitHub Releasesからの導入方法はxref:docs/user-guide/release-installation.adoc[インストールと更新]を参照してください。
Nix環境での実行と導入もxref:docs/user-guide/release-installation.adoc#nix-installation[Nixによる導入]を参照してください。

基本的な実行例:

[source,console]
----
# HTMLへ変換する
adocweave convert manual.adoc > manual.html

# CIでディレクトリ全体を確認する
adocweave check --fail-on warning --format github --summary docs

# 整形が必要かだけを確認する
adocweave format --check docs

# 確認後に複数のファイルを安全に整形する
adocweave format --diff docs
adocweave format --write docs
----

全オプション、標準入力、``include::``の扱いはxref:docs/user-guide/command-line.adoc[コマンドライン]を参照してください。

== 開発環境

Nix環境では、リポジトリのルートで次を実行します。

[source,console]
----
nix develop
cargo make verify
----

``cargo make verify``はPull Request用の標準検査です。source、依存関係、fuzz target、Nixパッケージ、
ブラウザーとエディターのadapter、HTML5標準適合性および文書を検査します。
