= 文書属性

文書の先頭で設定する`:`から始まる属性の書き方と、その効果を説明します。

== 記述位置

文書タイトルの直後に空行を挟まず記述された属性行を文書属性として解析する。
本文中やセクション見出し後の同じ表記は文書属性として扱わない。

[source,asciidoc]
----
= 文書
:project: AdocWeave
:stem: latexmath

本文
----

定義は`:name: value`、解除は`:name!:`または`:!name:`とする。属性名に使用できる
文字はASCII英数字、`_`、`-`および`.`である。syntax treeは空白、大小文字、改行および
解除形式を元のバイト列のまま保持する。

`Analysis::document_attribute_occurrences()`は、公開型`DocumentAttributeOccurrence`として名前、原値、
定義または解除の操作と各ソース範囲をsource順に返す。重複定義、空文字setおよびunsetは区別して
保持する。標準コアは属性名に応じたUUID、日時、タグ等への型変換を行わない。

`Analysis::presentation().attributes()`は最終的な属性値だけを返す。source-preservingな編集、保護属性の
置換またはhost固有の検証にはoccurrence queryを使用し、最終値だけが必要な変換・表示には後者を使用する。

== 属性参照

通常のインライン文脈では`{name}`を属性参照として解析する。属性値に別の参照が含まれる場合は
再帰的に展開する。循環、深さ上限または生成byte数上限に達した参照は原表記を保持し、
専用診断を生成する。ソース、リテラル、等幅文字および数式の内部では属性置換を行わない。
未定義参照は原表記を保持し、`undefined-attribute`診断を生成する。

`stem`は標準STEM構文の解釈時に意味を持つが、汎用属性AST自体では文字列として保持する。

== 保護属性

ホストは`ParseOptions.protected_attributes`へ権威的な属性値を渡せる。ソース中の定義
または解除がその値を変更する場合、寛容モードでは警告、厳格モードではエラーの
`protected-attribute`診断を生成する。コアは値をDBや環境から取得しない。

== アプリケーション固有メタデータ

`note-id`、`creator-id`、日時、タグ等の名前、型、必須性および正規化規則は標準AsciiDoc
の属性仕様ではない。これらは外部ホストが`Analysis::document_attribute_occurrences()`から検証・投影する。
規範仕様はxref:extensions.adoc[ホスト拡張実装仕様]を参照する。

== 対象外

* 条件分岐
* 環境変数または外部コマンド参照
* 本文の属性参照を用いた`include::` targetの動的な変更
* 本文途中での文書属性変更

preprocessor directiveは本文の属性置換とは別に、展開前snapshotの文書属性を用いて処理する。
詳細はxref:preprocessor.adoc[プリプロセッサとresource snapshot]を参照。
