= 今後の予定

この文書では、現在進行中の作業と着手を予定している作業の方向を示します。実施時期や公開日を
約束するものではありません。各作業の詳しい内容、依存関係および完了条件は、リンク先の
GitHub Issueを参照してください。

完了した作業の経緯はIssue、versionごとの変更は
https://github.com/KeishiS/AdocWeave/releases[GitHub Releases]のRelease Notesに記録します。
このページには完了したmilestoneの履歴を残しません。

== v0.11.xの保守

v0.11.xでは、公開API、WASM protocol、対応構文および既定のHTML出力契約を維持しながら、
確認済みの不具合、文書、依存関係および検証基盤を修正します。新しいCLI機能、公開schema、
既定診断および構文機能は次のminor release候補として扱います。

直近の変更は実利用の結果を確認します。patch releaseは、確認済みの修正が複数揃った時点、
または優先度の高い不具合を修正した時点で準備します。未完了作業のないrelease追跡Issueや、
版数を進めることだけを目的としたreleaseは作成しません。

== v0.12.0

v0.12.0では、AdocWeaveの対応profileにおいて、AsciiDoc pre-specに沿った本文中の属性定義、
再定義および解除に対応します。属性は文書の読込順に従って後続内容へ作用し、includeと
conditional directiveを含むすべての利用側が同じ属性environmentを使用します。

* https://github.com/KeishiS/AdocWeave/issues/35[本文中の属性定義・再定義・解除]
* https://github.com/KeishiS/AdocWeave/issues/61[属性の仕様・ADR・共有fixture]

parser、preprocessor、substitution、公開query、HTML、Lint、LSPおよびWASMを段階的に移行します。
公開Rust APIとWASM protocolの破壊的変更を許容し、位置ごとの値と定義元を明示できる契約へ
整理します。ほかの構文機能は同じreleaseへ追加しません。

== 継続運用

製品versionとは独立して、依存更新の安全な運用を改善します。

* https://github.com/KeishiS/AdocWeave/issues/19[Dependabot PRの安全な自動merge]

必須検査とbranch protectionを維持したまま、対象を限定した依存更新だけを段階的に
自動mergeできるか検証します。
