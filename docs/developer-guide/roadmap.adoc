この文書では、現在進行中の作業と着手を予定している作業の方向を示します。実施時期や公開日を
約束するものではありません。各作業の詳しい内容、依存関係および完了条件は
xref:../../issues/README.adoc[Issue一覧]を参照してください。

完了した作業の経緯はIssue、versionごとの変更は
https://github.com/KeishiS/AdocWeave/releases[GitHub Releases]のRelease Notesに記録します。
このページには完了したmilestoneの履歴を残しません。

== 開発と保守

製品機能のmilestoneとは独立して、文書検査と依存更新の運用を改善します。

* xref:../../issues/168-cli-local-target-validation.adoc[Issue 168: CLIによるlocal targetの実在検査]（計画）
* xref:../../issues/169-link-xref-lint.adoc[Issue 169: linkとxrefの使い分けに対するLint]（計画）
* xref:../../issues/170-list-lint-rules-json.adoc[Issue 170: Lint rule一覧のJSON出力]（計画）
* xref:../../issues/171-url-policy-responsibility-separation.adoc[Issue 171: URL検査の責務分割]（計画）
* xref:../../issues/172-html5-validator-fixture.adoc[Issue 172: 生成HTMLのHTML5適合性検査]（計画）
* xref:../../issues/166-dependabot-safe-auto-merge.adoc[Issue 166: Dependabot PRの安全な自動merge]（計画）

Issue 168では、`xref`、通常のlink、mediaおよび`include::`が参照するlocal fileの削除・移動漏れを
CIで検出できるようにします。Issue 169では、AsciiDoc文書とその他のfileに対する`xref`とlinkの
使い分けを通常のLintで検査します。Issue 170では、利用可能なLint ruleを実装からJSONで取得できるように
します。Issue 171では、URL構文、HTML出力、local file境界および実在性の検査を分離します。
Issue 172では、HTML断片を検証用テンプレートで包み、外部validatorによるHTML5適合性検査をCIへ
追加します。Issue 166では、必須検査とbranch protectionを維持したまま、対象を限定した依存更新だけを
自動mergeできるか検討します。
