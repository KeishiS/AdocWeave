v0.10.xでは、公開API、WASM protocol、対応構文および既定のHTML出力契約を維持しながら、
確認済みの不具合、文書、依存関係および検証基盤を修正します。新しいCLI機能、公開schema、
既定診断および構文機能は次のminor release候補として扱います。

* https://github.com/KeishiS/AdocWeave/issues/45[v0.10.1リリース準備]

patch releaseは、確認済みの修正が揃った時点、または優先度の高い不具合を修正した時点で準備します。
版数を進めることだけを目的としたreleaseは行いません。

== 開発と保守

製品機能のmilestoneとは独立して、文書検査と依存更新の運用を改善します。

* https://github.com/KeishiS/AdocWeave/issues/36[CLIによるlocal targetの実在検査]
* https://github.com/KeishiS/AdocWeave/issues/37[linkとxrefの使い分けに対するLint]
* https://github.com/KeishiS/AdocWeave/issues/32[Lint rule一覧のJSON出力]
* https://github.com/KeishiS/AdocWeave/issues/38[URL検査の責務分割]
* https://github.com/KeishiS/AdocWeave/issues/40[Macro境界のLint]
* https://github.com/KeishiS/AdocWeave/issues/19[Dependabot PRの安全な自動merge]

local targetの実在検査では、`xref`、通常のlink、mediaおよび`include::`が参照するfileの削除・移動漏れを
CIで検出できるようにします。linkとxrefのLintでは、AsciiDoc文書とその他のfileに対するmacroの
使い分けを検査します。Lint rule一覧では、利用可能なruleを実装からJSONで取得できるようにします。
URL検査の責務分割では、URL構文、HTML出力、local file境界および実在性を分離します。
Macro境界のLintでは、対応済みmacroに見える記述の境界誤りをopt-inで検出します。
Dependabotの運用改善では、必須検査とbranch protectionを維持したまま、対象を限定した依存更新だけを
自動mergeできるか検討します。
