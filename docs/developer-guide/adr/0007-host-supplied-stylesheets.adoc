= ADR 0007: ホスト供給スタイルシートの完全文書限定出力
:status: accepted

== 文脈

HTML backendは固定classとallowlistだけを出力し、生成HTMLの見た目を利用者が変更する手段を
提供していませんでした。一方で、入力由来の``style``属性、任意classおよびraw HTMLの拒否は公開仕様であり、
CSS対応のためにこの安全境界を緩めることはできません。CSSの適用先には、``<style>``本文の埋め込み、
``<link rel="stylesheet">``によるURL参照、fragment出力への混在、および検証済みstyle assetを
返す専用APIという候補がありました。

== 決定

スタイルシートは文書入力ではなく、ホストが明示的に指定する出力方針として扱います。
完全文書の``head``にだけ出力し、fragmentには混在させません。埋め込みCSSとURLはいずれも
信頼せず、出力前に検査します。具体的な入力型、検査規則、上限および診断は
xref:../html-contract.adoc[HTML出力の仕様]で定めます。

== 帰結

完全文書の``head``だけに型付きstylesheetを出力し、fragmentと入力由来styleの安全境界は
変更しません。標準themeの同梱は行わず、CSS本文の配布はホストの責務とします。
