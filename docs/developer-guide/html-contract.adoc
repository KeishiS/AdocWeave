= HTML出力の仕様

この文書では、生成HTMLの構造、出力規則および安全性の境界を定義します。CLIの操作方法は
xref:../user-guide/command-line.adoc[コマンドライン]、参照先やresourceの解決結果を渡す方法は
xref:server-execution.adoc#render-inputs[変換入力]を参照してください。

HTML出力はパッケージバージョンの一部であり、独立した仕様バージョンを持ちません。異なるパッケージバージョン間で
DOM構造、属性順、空白またはbyte列が同一であることは保証しません。

== 文書モード

``Fragment``は本文要素だけを出力する既定のモードです。``Complete``は文書型、言語未確定の``html``、
UTF-8 encodingと非空タイトルを持つ``head``および``body``を常に出力します。Stylesheetは同じ``head``へ
追加します。

[source,html]
----
<!doctype html>
<html lang="">
<head>
<meta charset="utf-8">
<title>AdocWeave document</title>
</head>
<body>
...
</body>
</html>
----

== スタイルシート

``RenderPolicy.stylesheets``は利用側アプリまたはCLIが明示的に渡す設定であり、文書入力からCSSへ到達する
経路はありません。埋め込みCSSと外部stylesheet URLを``Complete``の``head``へ指定順に出力し、同じ内容は
最初の一件だけを採用します。``Fragment``では出力せず、診断を返します。

埋め込みCSSでは、``style``要素を終了できる文字列、HTML comment開始文字列および不正な制御文字を拒否します。
外部URLは``ActiveUrlPolicy``で検査してから属性値としてescapeします。件数とbyte数には``StylesheetPolicy``を適用し、
拒否した値をHTMLや診断messageへ出力しません。

文書入力に由来する任意の``style``、classまたはraw HTMLは、stylesheet設定の有無にかかわらず拒否します。
この境界を採用した理由はxref:adr/0007-host-supplied-stylesheets.adoc[ADR 0007]に記録しています。

== 許可するHTML

生成する要素は次に限定します。

* 文書構造：`html`、`head`、`meta`、`title`、`body`、`style`、`link`、`figure`、`figcaption`
* 見出しと本文：``h1``から``h5``、`p`、`div`、`br`、`hr`
* インライン：`a`、`strong`、`em`、`code`、`mark`、`span`、`sub`、`sup`、`kbd`
* ブロック：`pre`、`blockquote`、`cite`
* list：`ul`、`ol`、`li`、`dl`、`dt`、`dd`
* table：`table`、`caption`、`thead`、`tbody`、`tfoot`、`tr`、`th`、`td`
* media：`img`、`audio`、`video`

属性は``lang``、`charset`、`id`、`class`、`href`、`src`、`alt`、`width`、`height`、`title`、`controls`、
`poster`、`target`、`rel`、``colspan``、``rowspan``、``data-language``、``data-line-numbers``および
``data-line-start``、``data-math-language``および``data-math-display``に限定します。
classには実装が列挙する固定値だけを使用します。
入力由来の任意属性、event handler、`script`、SVGおよびraw HTMLは生成しません。

``target``と``rel``は外部HTTP(S) linkの固定表示と外部stylesheetだけに使用します。入力に書かれた同名属性を
そのまま通過させません。

完全HTML文書には``doctype``、`html`、`head`、UTF-8の``meta``、非空の``title``および``body``を常に出力します。
文書タイトルがある場合は構造モデルのタイトル文字列をinline記法として再解釈せず、escapeして``title``へ
使用します。タイトルがない場合は固定の代替タイトルを使用します。言語を推測せず、``html``の``lang``には
未知を表す空文字列を出力します。

Tableの``width``は1から100までの値を百分率として正規化し、``%``付きで出力します。Captionは安全な
literal textとしてescapeし、inline書式や属性参照を再解析しません。

順序付きlistの``start``、``reversed``および番号形式は型付きpresentationへ保持しますが、公開属性allowlistに
含まれない``start``、``reversed``、``type``および``style``へ変換しません。HTMLでは通常の``ol``として出力します。

== URLとリソース

URLは由来を示すcontextとともに``RenderPolicy.active_urls``の``ActiveUrlPolicy``で検査します。
文書に記述されたlink、
解決済みxrefおよび解決済みresourceを区別し、利用側アプリが返したURLも信頼済みとして扱いません。

制御文字、空白、不正なscheme、絶対filesystemのpath、backslash、ネットワーク-path referenceおよびpath traversalを
拒否します。許可するscheme、root-relative URL、外部画像およびdata URIはpolicyで明示します。
root-relative URLの許可は解決済みの値だけに適用し、文書へ直接記述した値へは適用しません。

``javascript``と``vbscript``は、利用側アプリが許可schemeへ加えても出力しません。これらはbrowserが
codeとして実行するURLであり、許可する設定を受け付けること自体が誤りだからです。この保証はstylesheetの
検査と同じ考え方です。``data``はこの一覧に含めません。data URIは実行されない内容を運び、独自の設定項目を
持つためです。

解決できない参照、拒否したURLおよび利用できないresourceはactive要素へ変換せず、表示文字列や代替文字列を
escapeした非activeな内容として出力します。解決済み表示文字列はプレーンテキストとして扱い、AsciiDocや
HTMLとして再解析しません。詳しいfallback規則はxref:server-execution.adoc#render-inputs[変換入力]を
基準とします。

画像、音声および動画は、解決済みURL、macro種別と一致するMIME typeおよび対応する
``ResourceCapabilities``がある場合だけactive要素として出力します。MIME typeはASCIIの大文字と小文字を
区別せず、parameterを除いたtypeとsubtypeを検査します。拡張子からMIME typeを推測しません。

Imageとiconには``image/*``、audioには``audio/*``、videoには``video/*``を要求します。Imageはalt、寸法、title、
iconはaltとtitle、audioはtitle、videoは寸法、poster、titleを出力できます。寸法には10進整数だけを使用します。
``controls``はaudioとvideoへ常に付与し、入力から無効化しません。Video posterは独立した``image/*`` resourceとして
URLとMIME typeを検査します。posterだけを利用できない場合は診断を返してposterを省略し、安全なvideo本体は
維持します。Mediaのlink化、icon set固有の要素・classおよびその他の再生属性には対応しません。

== HTML5標準適合性検査

生成HTMLの標準適合性は``cargo make html5-check``で検査します。検査対象は
``fixtures/html/validation.json``で一意に管理し、断片出力は同ディレクトリの固定テンプレートで完全HTML文書へ
変換します。完全文書出力は包まず、そのまま検査します。生成物は``target/html5/``だけへ書き込みます。

Validatorには``flake.lock``で固定したNixpkgsのNu Html Checkerを使用し、manifestにバージョンと実行optionを
記録します。errorとwarningをいずれも失敗として扱い、言語推定だけを無効にします。既知違反のallowlistは
設けません。不正な入れ子、標準外属性および不完全な文書のnegative fixtureがvalidatorで拒否されることも
同じtaskで確認します。

この検査はHTML5標準への適合性だけを担当します。Golden fixtureのbyte比較、要素・属性allowlist、
URL policy、安全性検査およびnativeとWASMの一致検査は引き続き独立して実行します。

== ソースと数式

Source blockの言語classは``SourceLanguagePolicy``で許可した言語だけに付けます。未知の言語ではclassを
省略して診断を返します。

Block titleまたは``linenums``を持つsource blockは``figure.source-block``で囲み、titleを``figcaption``へ
inline装飾を除いた解決済みplain textとして安全に出力します。Projectionのtitleも同じplain textです。
``pre``の``data-language``、``data-line-numbers="true"``および``data-line-start``は
projectionと同じ言語、行番号指定および開始行を表します。行番号要素、構文強調、themeおよび操作buttonは
生成しません。Titleも行番号指定もない従来のsource blockは既存の``pre > code.language-*``構造を維持します。

数式engineは内蔵しません。許可した数式言語だけに固定class、``data-math-language``および
``data-math-display``を付け、内容は常にescapeします。LaTeXは``latexmath``、表示形式は``inline``または
``block``です。Inline数式は``code``、block数式は``pre``内の``code``として出力します。利用側は要素名や
親子関係を推測せず、この二つの属性とescape済みのtext contentを数式描画adapterへ渡せます。
JSON／WASM protocolでは既存の言語enum値``latex``を維持し、``latexmath``はAsciiDoc構文とHTML属性の名前に
限定します。

== 決定性

同じパッケージバージョン、解析結果、``RenderPolicy``および``RenderInputs``からは同じHTMLを生成します。
属性順、改行、空白および末尾改行はテスト用の期待出力で固定し、変更時は意図した差分であることを
確認します。

== 公開適合性fixture

利用側はlink:../../fixtures/public-conformance.json[公開適合性fixture]で、入力AsciiDoc、投影、
HTML、解析診断および描画診断の対応を検査できます。各caseに記録したanalysis profileとrender profileを
適用し、``stableContract``のJSON pointer、HTML断片および診断codeを比較します。

公開fixtureは次の構文を分離して扱います。

* 文書タイトル、TOCおよび節番号
* block title、source language option、linenumsおよび開始行を記述したsource block
* 未対応source optionの診断と安全なlisting回復
* inline数式およびblock数式
* table、quoteおよびlist
* 安全でないURLの解析診断、描画診断および非active HTML fallback

公開仕様は``stableContract``に列挙した意味上の値とHTML構造だけです。期待出力ファイル全体はAdocWeave内の
決定性とruntime間の一致を検査するgolden fileであり、JSONのkey順と空白、HTMLの属性順、字下げ、
空白、末尾改行および未選択の投影fieldは利用側の安定APIではありません。利用側はこれらのbyte列を
固定せず、必要な項目だけを選択して検査します。

Source blockではtitle、language、option、linenums、開始行およびsource本文と、対応する安全なHTML構造を
保証します。数式ではprojectionのlanguage ``latex``、表示形式``inline``または``block``、source本文と、
HTMLの``data-math-language="latexmath"``および``data-math-display``を保証します。Tableのcell構造、
quoteの追加presentationおよびlist itemを表す未選択のprojection fieldは現行の公開仕様に含めず、tableとlistの
HTML断片、およびquoteの既存``blockPresentations``だけを保証します。

== golden fixtureの保守

期待出力fileは手で書き換えず、現在の実装から書き出します。公開適合性fixtureと、native・WASM間の
一致を検査する共有fixtureのそれぞれに、書き出すコマンドと、ファイルがその書き出し結果と一致することを
検査するtestがあります。

[source,console]
----
cargo test -p adocweave --test public_conformance_fixture regenerate_public_fixture_products -- --ignored
cargo test -p adocweave-wasm --test conformance regenerate_shared_fixture_products -- --ignored
----

書き出すコマンドはgateに含めません。golden fileは、実装の変更が公開仕様へ与えた影響を見えるようにする
ためのものであり、読まずに上書きするとその目的が失われます。公開仕様を変えたときは、コマンドを実行してから
差分を1件ずつ読み、意図した変更だけであることを確かめてコミットします。

一致を検査するtestはgateに含めます。これにより、ファイルの整形が書き手ごとに揺れることも、複数のcaseが
参照するfileの更新漏れも、コミット前に分かります。

共有fixtureのcaseの一部は、公開適合性fixtureのfileをそのまま期待出力として参照します。これらのfileは
公開適合性fixture側のコマンドが書き出し、共有側は書き換えません。一つのfileを二つのコマンドが
書き換えると、どちらを実行したかで内容が変わるためです。
