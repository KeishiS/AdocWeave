= 公開している仕様

このページは、AdocWeaveをライブラリやWebAssemblyとして使う人のための入口です。
公開API、JSONの入出力、HTMLの出力は、すべてリリース番号で対応関係を確認します。
version固有の変更内容と移行手順は
https://github.com/KeishiS/AdocWeave/releases[GitHub Releases]のRelease Notesを参照してください。

作業の経緯はIssue、設計を選んだ理由はADR、今後の予定はロードマップに分けて記録しています。

== Version方針

現在のpackage versionとRust versionはxref:../release-manifest.json[release manifest]を基準とします。
サポート対象は最新releaseだけです。CLI、LSP、WASM、browser package、Zed拡張および保存済み成果物を
異なるpackage versionの間で混在させず、更新時は同じversionへ揃えてHTMLや検索情報を再構築してください。

== 文書の分類

このディレクトリは現行仕様を記述する。xref:adr/index.adoc[ADR]は採用済みの長期的な
設計判断、xref:roadmap.adoc[ロードマップ]はmilestoneごとの計画と完了概要、xref:../issues/README.adoc[Issue]は
詳細な完了履歴と作業単位を記録する。
version固有の変更内容と移行手順はGitHub Release Notesを正本とする。
Issue本文を現行仕様の基準として参照してはならない。
