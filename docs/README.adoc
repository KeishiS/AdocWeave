= AdocWeaveの文書

このディレクトリには、利用方法、対応書式、アプリケーションへの組み込み、開発方法を記載します。

== Version方針

現在のパッケージバージョン、RustおよびNode.jsのバージョンは次のファイルを基準とします。
link:../release-manifest.json[release manifest]

version固有の変更内容と移行手順は
https://github.com/KeishiS/adocweave/releases[GitHub Releases]を参照してください。

== ディレクトリの案内

user-guideディレクトリには、利用目的、操作、入力および結果を利用者の視点で記載します。
実装内部の説明は、操作結果を理解するために必要な範囲に限定します。
developer-guideディレクトリには、アプリへの組み込み、実装、配布および設計について、
コンポーネントの責務、境界、不変条件および検証方法を記載します。基本的な操作手順は
user-guideと重複させません。
採用した設計とその背景はdeveloper-guide内のADR、
現在の主要な計画はロードマップ、作業単位はGitHub Issuesに記録します。
完了した作業の経緯はGitHub Issues、Pull RequestおよびGit履歴から確認します。

== このリポジトリで使用する用語

この節は、AdocWeave固有の考え方を表す語の意味を定めます。一般名詞を日本語と原綴りのどちらで
書くかは、xref:developer-guide/terminology.adoc[用語の表記]を基準とします。

[cols="1,3",options="header"]
|===
|表記 |この文書での意味

|公開仕様(contract)
|ライブラリや配布物を利用するプログラムとの取り決めです。

|対応範囲(profile)
|AdocWeaveが受け付け、期待どおりに処理するAsciiDocの範囲です。

|意味情報(semantic model, projection)
|解析して得た、見出し・リンク・表・属性などの構造化された情報です。

|利用側アプリ(host)
|AdocWeaveを呼び出すCLI、エディター、Webアプリなどです。

|テスト用入力(fixture)
|期待する結果と組で保存する入力例です。

|===
