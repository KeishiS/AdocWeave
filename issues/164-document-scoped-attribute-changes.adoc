= 文書内属性変更の評価
:status: planned
:depends-on: 029, 147

== 目的

文書header後に現れる標準AsciiDocの属性定義と解除について、後続内容へ適用される文書内状態変更を
表現する。最終属性値とsource-preservingなoccurrence queryを維持しながら、位置ごとの有効値を
host非依存coreで決定できるようにする。

== 作業

* 属性変更を許可するblock境界、適用開始位置、解除、再定義および未定義参照の規則を定める。
* include、conditional directive、protected attributeおよびhost提供属性との所有権境界を整理する。
* occurrence列から位置依存の属性environmentを導出し、全nodeごとのmap複製を避ける。
* parser、substitution、formatter、HTML、Lint、LSPおよび公開queryの影響範囲を定義する。
* document attributes、grammar、substitutions、compatibilityおよびfixtureを同期する。

== 対象外

OS環境変数や外部I/Oからの暗黙注入、host固有属性の型検証、include先resourceの取得は扱わない。

== 完了条件

* 任意のsource位置で有効な属性値と、その値を決めたoccurrenceを公開queryから取得できる。
* 解除、再定義、forward referenceおよびprotected attributeの結果が規範文書とテストで一致する。
* native、WASM、HTML、LintおよびLSPが同じ位置依存environmentを利用する。
* 文書規模に比例しない属性map複製を導入せず、既存の最終値・occurrence APIを壊さない。
