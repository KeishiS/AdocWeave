= Tableの自動header推論
:status: planned
:depends-on: 093

== 目的

明示的な`options="header"`がないtableで、標準AsciiDocの規則に従って先頭行をheaderとして推論する。
既存の入力形式、separatorおよびcell semanticを変えず、推論結果をnative、WASM、HTMLおよびLintで
一致させる。

== 作業

* PSV／CSV／DSV／TSVとAsciiDoc block cellについて、自動header推論を適用する条件と抑止条件を規範化する。
* 明示`header`／`noheader`、空行、comment、複数物理行のcellおよび不完全入力の優先順位を定める。
* `TableInputSpec`とtable semantic modelのどちらが推論結果を所有するかを一意にする。
* formatterが利用者の明示指定を保持し、暗黙の推論を不要に実体化しないことを確認する。
* grammar、table文書、syntax support、compatibilityおよび共通fixtureを同期する。

== 完了条件

* 標準AsciiDocの代表例と境界例について、header rowの有無がAsciidoctorと一致する。
* 明示`header`／`noheader`が自動推論より優先される。
* native、WASM、HTML、Lintおよびformatterで同じtable semanticを共有する。
* strict／tolerant modeの不完全入力で決定的な診断または回復結果を返す。
