== 設計判断

runtime動作、公開API、対応するAsciiDoc構文、公開仕様version、配布targetおよびartifact構成を変更しないため、
patch releaseとします。release manifestの`packageVersion`を機械可読な基準とし、Rust 1.97.1を維持します。
mainの完全candidate成功commitへstable tagを一度だけ付けます。

* `RELEASE_TAG=v0.8.1 cargo make release-gate`が成功します。
