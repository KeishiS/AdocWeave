= fuzz target の入力

このディレクトリには、各fuzz targetへ与える既知の入力を置きます。``cargo make fuzz``はこれらを
一時ディレクトリへ複写し、各targetを短時間実行して、落ちないことを確認します。

fuzz targetは回帰の確認に使います。探索のために長時間動かす運用は行いません。この判断の理由は
xref:../../docs/developer-guide/server-execution.adoc[サーバー実行仕様]に記載しています。

== 入力を足すとき

実際に不具合を見つけた入力を加えます。その入力をここへ置くことで、同じ経路の再発を以後の検査が
捉えます。

生成された入力を自動で蓄積することはしません。実行のたびに差分が出ると、Pull Requestのreviewで
何を見ればよいのか分からなくなるためです。

ファイル名は、その入力が通す経路が分かるものにします。``include``、`tags`、``lines``のように、
何を検証しているかを名前で示してください。
