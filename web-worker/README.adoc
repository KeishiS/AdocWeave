= AdocWeave browser package

このarchiveは、AdocWeaveのWebAssembly moduleとWeb Worker adapterを同じversionで提供します。
公的なpackage registryへは登録せず、リポジトリ所有者のGitHub Releasesから取得して展開します。

== 内容

* ``wasm/adocweave_wasm.js``と``wasm/adocweave_wasm_bg.wasm``：``wasm-bindgen``のweb向け成果物
* `wasm/adocweave_wasm.d.ts`：生成された場合のTypeScript declaration
* ``worker/index.mjs``と``worker/index.d.mts``：frontend向けの公開ES module入口と型定義
* `worker/client.mjs`、`worker/controller.mjs`、`worker/worker.mjs`：最新generationだけを採用する内部実装
* `worker/contracts.mjs`：公開パッケージ版
* ``worker/protocol.generated.mjs``と``worker/protocol.generated.d.mts``：schema 6の生成済み公開型と版数
* `THIRD_PARTY_NOTICES.adoc`：rootとZedのlockfileから生成したthird-party package一覧

== 最小例

[source,javascript]
----
import { analyzeOnce, defaultAssetUrls } from "./worker/index.mjs";

const result = await analyzeOnce(defaultAssetUrls(), {
  version: 1,
  source: "= Title\n\nAsciiDoc text",
});
// HTMLの信頼方針はホストが決めます。この例では文字列として表示します。
preview.textContent = result.html;
----

``analyze()``と``onResult``は、``sourceVersion``、``generation``、HTML、診断、symbolおよび
projectionを一つの結果として返します。``result.result``は存在せず、すべてのWASM productを
``result.projection``のように結果直下から参照します。要求しなかった``projection``は``null``、
要求しなかった配列productは空配列です。

公開入口がWorkerの生成、初期化、debounce、generation、cancelおよびdisposeを所有します。
``SharedArrayBuffer``を利用できない場合はWorker再生成へ自動的に縮退します。DOMへの反映とUI stateは
利用側が所有します。連続更新では従来どおり``update()``、``onResult``および``onError``を使用できます。
``onResult``または``onError``内で発生した例外は解析PromiseとWorkerへ伝播しません。例外の記録や
画面表示が必要な場合は、callback内で処理します。
``defaultAssetUrls()``は``import.meta.url``を基準にWorkerとWASMを解決するため、静的hostingとbundlerの
どちらでも同じ公開入口を使用できます。moduleのimportだけではWorkerを生成しません。
Clientの構築時にもWorkerやWASM network requestは開始せず、``ready``の参照または``analyze()``で初めて
Workerを初期化します。Fallback modeで未完了の``ready``と``analyze()``を同時に開始した場合、
``analyze()``側のWorkerを採用し、先に取得した``ready``は``superseded``でrejectします。
動作するtextarea例は``example/index.html``に含まれます。APIと返却値の詳細は
xref:../docs/developer-guide/core-profile.adoc#wasm-api[WebAssembly API]を参照してください。

ViteまたはWebpackではbrowser release packageの``worker``と``wasm``を同じ公開directoryへ資産として
コピーし、配備後の``worker/index.mjs`` URLを``defaultAssetUrls``へ渡します。WorkerとWASMをJavaScript
bundleへinline化せず、返されたURLをそのまま使用します。この配置はcontent hash付きbase URLとCDN URLでも
同じ相対関係を維持します。Release gateでは実packageをesbuildでbundleしたbrowser smoke、CSP、WASM size
およびURL解決を検証します。
